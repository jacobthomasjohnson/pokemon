# Pokemon Battle Simulator

A turn-based battle sequence built with Next.js, React, Tailwind CSS, Zustand, and Motion. A fan project for practicing game state, turn timing, and UI animation.

## What it does

- **Turn-based combat**: the player picks an attack, then the opponent responds on a timer.
- **Animated HP bars** that show when an attack lands.
- **Inventory menu** with expandable modals. Potions are consumed and reduce the item count.
- **Opponent behavior**: the enemy can attack or use a potion on its turn, with balanced move and potion probabilities.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.
